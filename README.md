🎾 Tenis 2D

Un sencillo juego de tenis en 2D para dos jugadores en local, inspirado en los clásicos juegos arcade. Cada jugador controla su raqueta y debe devolver la pelota para conseguir puntos.

🎮 Controles
Jugador 1: W para subir y S para bajar.
Jugador 2: O para subir y L para bajar.

¡Pon a prueba tus reflejos y consigue más puntos que tu rival para ganar el partido!
